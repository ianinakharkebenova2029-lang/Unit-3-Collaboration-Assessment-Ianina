## 2. Why do developers use branches? 

Developers use branches to work on new ideas and continue working on a project without affecting the main branch.

## 3. What is Git? What is Github? How does git and github work together?

Git is:

-  Command line tool that allows developer to track and manage changes to their code

- Distributed Version Control System 

- What developers use to take a snapshot of what the code looks like at the moment.

- A tool, allows us to interact with other repos

Github is: 

- Cloud based service that allows developers to store, track, mahage, and control changes to their code

- Web based platform to store repos in the cloud and collaborate with other developers

Git is a tool in Github.com platform. When the developers work on github, git helps them to control everything there.
